# Agent Skills

Private/internal Agent Skills for integrating with the [Serial Subscriptions](https://serialsubscriptions.com/) platform via `@serialsubscriptions/platform-integration`.

## Install

```bash
npx skills add serialsubscriptions/skills
```

## Available Skills

| Skill | Description |
|-------|-------------|
| [ssi-platform-integration](ssi-platform-integration/) | Session management, authentication, subscription plans, usage reporting, and caching via `@serialsubscriptions/platform-integration` |
